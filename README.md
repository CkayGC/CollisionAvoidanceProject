# Agent Navigation Simulation

An interactive browser simulation where agents move between nodes. Add or remove agents and nodes, pause or resume the simulation, and adjust settings for movement limits, path previews, and agent avoidance.

## Built with

- React and TypeScript for the interface and simulation logic
- HTML Canvas for real-time rendering
- React for development and build tooling

## Skills demonstrated

- Real-time simulation
- Vector math
- Motion and trajectory prediction
- Agent navigation
- Conflict detection
- Interactive canvas controls
